# Development

## Prerequisites
- Node.js
- npm

## Setup & Workflow
- **Setup:** `npm install`
- **Build:** `npm run build`
- **Dev:** `npm run dev` (watch mode)
- **Test:** `npm test`
- **Type check:** `npm run lint`

## Loading the Extension
1. Go to `chrome://extensions`.
2. Enable "Developer mode" in the top right.
3. Click "Load unpacked".
4. Select the `dist/` directory generated by the build.

## Debugging
- Enable the debug toggle in the extension's options page.
- Check the page DevTools console for `[Declank]` logs.

## Adding a New Filter
1. Implement the `CommentFilter` interface.
2. Register the filter in `filterEngine.ts` inside `buildFilters()`.
3. Add settings to `ExtensionSettings`.
4. Add the configuration UI to `OptionsApp.tsx`.

## Project Structure Overview
- `src/` - Source code.
- `docs/` - Documentation.
- `dist/` - Built extension (generated).
- `public/` - Static assets.
